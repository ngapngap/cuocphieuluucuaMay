# Polyfork model credits

These game files include work by Polyfork under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). The game uses local copies.

The bear, deer, mountain hare, rabbit and wolf animations were resampled to remove redundant keys. The game also distributes a gzip copy of the startup rabbit and sheep.

| Game file | Original model by Polyfork | Changes in this game |
| --- | --- | --- |
| polyfork_bear.glb | [Bear](https://polyfork.dev/asset/bear-base) | New sculpt and painted coat variants for panda and polar bear, skinned to the Polyfork skeleton and animations. The frost bear uses the same rig. |
| polyfork_rabbit.glb | [Rabbit](https://polyfork.dev/asset/rabbit-base) | New sculpt with white and chestnut coats, skinned to the Polyfork skeleton and animations. |
| polyfork_hare.glb | [Mountain hare](https://polyfork.dev/asset/mountain-hare-base) | New sculpt and winter coat, skinned to the Polyfork skeleton and animations. |
| polyfork_wolf.glb | [Wolf](https://polyfork.dev/asset/wolf-base) | Reduced skin influences and recolored at runtime for the snow boss. |
| polyfork_deer.glb | [Deer](https://polyfork.dev/asset/deer-base) | Reduced skin influences and added cream spots to both flanks. |
| polyfork_sheep.glb | [Sheep](https://polyfork.dev/asset/sheep-base) | Optimized geometry and animation data. |
| polyfork_camel.glb | [Camel](https://polyfork.dev/asset/camel-base) | Optimized geometry and animation data. |
| polyfork_owl.glb | [Owl](https://polyfork.dev/asset/owl-base) | Optimized geometry and animation data. |
| polyfork_penguin.glb | [Penguin](https://polyfork.dev/asset/penguin-base) | Optimized geometry and animation data. |
| polyfork_octopus.glb | [Octopus](https://polyfork.dev/asset/octopus-base) | Reduced triangle count and skin influences. The eight arms retain independent motion. |
